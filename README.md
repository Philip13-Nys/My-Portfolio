# Philip Miguel — Web Developer Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, and Tailwind CSS. It includes selected projects, skills, about, certifications, experience, resume placeholder, and contact sections.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The contact form uses FormSubmit to deliver messages to the portfolio email address. The first submission may require confirming the address with FormSubmit.
